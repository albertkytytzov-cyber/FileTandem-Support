# FileTandem Support

Public privacy policy, support documentation, and issue tracker for FileTandem
on macOS and the optional, separately distributed FileTandem Companion for
Android. The Mac app's USB and standard wireless ADB paths do not require the
companion.

- [Support](https://albertkytytzov-cyber.github.io/FileTandem-Support/support.html)
- [Privacy policy](https://albertkytytzov-cyber.github.io/FileTandem-Support/privacy.html)
- [Report an issue](https://github.com/albertkytytzov-cyber/FileTandem-Support/issues/new/choose)
- Private support: [albert.kytytzov@gmail.com](mailto:albert.kytytzov@gmail.com)

The application source is maintained separately. Do not attach private files, passwords, pairing codes, or device serial numbers to public issues.

The files in this directory are the publication source. Editing them does not
change the live GitHub Pages site until the separate `FileTandem-Support`
repository is updated and deployed.
