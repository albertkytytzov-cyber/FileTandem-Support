FileTandem Support

Setup instructions and practical fixes for transferring files between Mac and Android.

Open a support request Known issues

GitHub issues are public. Never include private files, passwords, pairing codes, device serial numbers, or other sensitive information.

Connect an Android device by USB

  1. Use a USB cable that supports data and unlock the Android device.
  2. For ADB, enable Developer options and USB debugging, then approve the Mac on the phone.
  3. For MTP, choose File transfer in the Android USB notification when available.
  4. Launch FileTandem and select the device in the sidebar.

Copy files

Select files or folders in either panel. Use the center controls to copy them to Android or to Mac. Progress and cancellation controls appear in the transfer queue.

If the device is not detected

  • Reconnect the cable and try another USB data cable or USB port.
  • Keep the Android device unlocked and select File transfer mode.
  • Revoke USB debugging authorizations on Android, reconnect, and approve the Mac again.
  • Close other Android transfer or ADB tools that may already control the device.
  • In FileTandem settings, reduce simultaneous transfers to 1 for an unstable cable or device.

Wireless ADB

Keep both devices on the same trusted local network. In Android Developer options, open Wireless debugging, choose pairing by code, and enter the displayed address and code in FileTandem. Wireless ADB is optional.

Android companion

When FileTandem Companion is available, choose folders with Android’s system picker, pair only with a Mac you recognize, and use the app’s Revoke control when access is no longer needed.

Compatibility

The Mac app requires macOS 15.4 or later. ADB and MTP behavior can vary by Android version, manufacturer, cable, and USB mode.

Поддержка на русском

Подключите разблокированный Android качественным USB-кабелем. Для ADB включите «Для разработчиков» и «Отладка по USB», затем подтвердите доверие к Mac. Для MTP выберите режим «Передача файлов». Если устройство не видно, смените кабель или порт, повторно подтвердите отладку и закройте другие программы ADB.
