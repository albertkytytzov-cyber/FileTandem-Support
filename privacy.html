Privacy Policy

FileTandem moves files directly between devices you control. There is no FileTandem account, advertising, analytics, tracking, telemetry, or developer-operated transfer server.

Effective September 7, 2026 · Developer: FileTandem / albertkytytzov-cyber

Scope

This policy covers the FileTandem app for macOS and the optional FileTandem Companion for Android. Features described for the Android companion apply only when that app is made available.

Data collection and sharing

FileTandem does not collect, sell, or share personal data with the developer or third parties. It contains no advertising, analytics, tracking, or telemetry SDKs. The developer cannot see the files, filenames, device identifiers, pairing information, or transfer activity processed by the apps.

Files and device metadata

The apps process filenames, folder names, sizes, timestamps, device information, and file contents only on the user’s devices to display folders, preview files, and perform operations the user requests. Files are sent only to the destination device or storage provider selected by the user.

macOS access

App Sandbox restricts the Mac app to Downloads, folders selected by the user, connected USB devices, the local network when the user enables a wireless feature, and app-managed storage. Finder integration uses Apple’s File Provider framework.

Android access

The Android companion uses Android’s system folder picker (Storage Access Framework). It can access only folder trees explicitly granted by the user. Grants, paired-device identity, and preferences are stored locally and can be revoked in the app or Android system settings. The app does not request broad “all files” access.

Local-network transfers and security

Wireless features communicate directly between the paired Mac and Android device on the local network. FileTandem does not route transfers through a developer-operated relay or cloud service. Pairing credentials and trusted peer information are stored locally. Users should pair only on a network they trust and revoke devices they no longer use.

Third-party storage providers

If a user selects a folder exposed by a third-party Android document provider, that provider may separately synchronize the selected content according to its own privacy policy. FileTandem does not control that provider or send content to it independently.

Retention and deletion

FileTandem has no server-side account or personal-data record. Local preferences, cached previews, folder grants, and paired-device records remain on the device until the user revokes them, clears app data, or removes the app. Files copied to a user-selected destination remain until the user deletes them.

Children

FileTandem is a general-purpose utility and is not directed specifically to children. The developer does not knowingly collect personal data from children or any other users.

Changes

If FileTandem’s data practices change, this policy and the relevant store disclosures will be updated before the changed version is released. The effective date at the top identifies the current version.

Contact

For privacy or support questions, open a request through FileTandem Support on GitHub. Do not include private files, device serial numbers, passwords, pairing codes, or other sensitive information in a public issue.
